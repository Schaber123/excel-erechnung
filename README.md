## Was ist das?

Das **Excel eRechnung Tool** ist ein Desktop-Konverter für Windows und macOS, der bestehende Excel-Rechnungsvorlagen in gesetzeskonforme **XRechnungen (XML nach EN 16931)** und **ZUGFeRD-PDFs** umwandelt — vollständig offline, ohne Cloud, ohne monatliche Kosten.

Ideal für Freelancer, Handwerksbetriebe und KMU, die Excel behalten möchten und trotzdem die **eRechnungspflicht ab 2025** erfüllen müssen.

---

## Features

- ✅ **XRechnung (XML)** nach EN 16931 / UBL erstellen
- ✅ **ZUGFeRD-PDF** (hybrides Format mit eingebettetem XML) erstellen
- ✅ **KoSIT-Validator integriert** — automatische Normprüfung vor dem Versand
- ✅ **Excel Add-in** für direkten Export aus der Tabelle (VBA-Modul)
- ✅ **Eigene Excel-Vorlage** weiterverwenden — konfigurierbares Mapping, einmalig einrichten
- ✅ **Vollständig offline** — keine Daten verlassen den PC, keine Cloud-Abhängigkeit
- ✅ **Windows 10/11 + macOS** — keine Python-Installation nötig

---

## So funktioniert es

```
1. Excel ausfüllen   →   Rechnungsdaten in Ihre gewohnte Vorlage eintragen
2. Exportieren       →   Auf "eRechnung erstellen" klicken — KoSIT-Validierung läuft automatisch
3. Versenden         →   XRechnung-XML + ZUGFeRD-PDF liegen im Ausgabeordner
```

## FAQ

**Funktioniert das Tool mit meiner bestehenden Excel-Vorlage?**

Ja. Jede Rechnung wird automatisch durch den offiziellen KoSIT-Validator geprüft.

**Brauche ich eine Internetverbindung?**  
Nein. Alles läuft vollständig offline auf Ihrem PC.
